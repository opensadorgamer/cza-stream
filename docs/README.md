# Meet & Chat Pro - Discord Edition

Arquitetura profissional refatorada com módulos ES6 reais, Supabase Realtime, e WebRTC otimizado sem necessidade de atualização (F5).

## Estrutura de Pastas
- `/index.html` - Página principal da aplicação
- `/css/` - Estilos customizados e animações
- `/js/` - Módulos JS organizados (config, supabaseClient, auth, rooms, cameraMic, screenShare, signaling, webrtc, chat, interface, main)
- `/assets/` - Recursos estáticos e imagens
- `/docs/` - Documentação do projeto
